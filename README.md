# Ultra Pro Max Professional Website Cloning Utility

Overview:
A lightweight, high-performance website cloning and local hosting utility built with Python, Flask, and Requests. Designed for developers and security researchers to inspect, mirror, and analyze web structures locally.

Features:
- Local Mirroring: Fetches target web assets safely for local viewing.

## Menu Options & Step-by-Step User Guide

### Option 1: Local Site Structure Simulation
* **What it does:** Generates an isolated local site layout simulation without fetching external network resources.
* **How to use:** 
  1. Select option `1` from the main menu.
  2. Enter a custom **Title** when prompted.
  3. Enter the **Purpose** of your simulation.
  4. The tool will instantly generate and display the localized layout parameters.

### Option 2: Secure Mirror (10-Step + Safe Browsing Check)
* **What it does:** Scans target URLs via a Google Safe Browsing simulation, executes a 10-step security header validation, clones the assets safely, and spins up a persistent local Flask server.
* **How to use:**
  1. Select option `2` from the main menu.
  2. Input a valid **Target URL** (e.g., `https://example.com`).
  3. Select your preferred interface language (`bn`, `hi`, or `en`).
  4. Monitor the terminal as the 10-step defensive progress bar finishes.
  5. Once completed successfully, the tool will launch the local server and display the access URLs:
     * **Localhost URL:** `http://127.0.0.1:5000`
     * **Network URL:** `http://0.0.0.0:5000`
  6. Copy and paste the URL into your browser to view the cloned instance. Press `Ctrl + C` in the terminal to stop the server.

### Option 3: VIP Unrestricted Defensive Engine
* **What it does:** Unlocks advanced diagnostic features and direct secure mirroring for authorized users using a cryptographic signature key.
* **How to use:**
  1. Select option `3` from the main menu.
  2. Enter your authorized **Cryptographic VIP Key**.
  3. Enter the target URL and language code upon successful authentication.
  4. Follow the multi-layer defensive progress output until the persistent local Flask server initializes and provides the browser access link.

### Option 4: Exit Toolkit
* **What it does:** Safely exits the application.
* **How to use:** Select option `4` to terminate the utility loop.
